# 一人公司SOP生成器

> 根据业务类型和团队规模自动生成标准化操作流程的工具

---

## Features / 功能特点

| 功能 | 说明 |
|------|------|
| 业务类型选择 | 电商/实物产品、服务/咨询、内容/自媒体、工具/SaaS |
| 团队规模 | 仅自己、1-2人、3-5人、5人以上四种规模适配 |
| 发展阶段 | 起步期/成长期/稳定期三阶段个性化配置 |
| 客服与服务 SOP | 响应时效、标准流程、常见问题模板 |
| 财务与账务 SOP | 记账、开票、税务、成本控制流程 |
| 营销推广 SOP | 内容计划、获客流程、广告投放方案 |
| 产品交付 SOP | 需求规划、交付流程、质量标准规范 |
| 保存管理 | 保存和加载历史SOP方案 |
| 导出Markdown | 一键导出完整SOP文档，方便分享 |

## Installation / 安装

无需安装，直接在浏览器中打开 `index.html` 即可使用。

```bash
# 克隆仓库
git clone https://github.com/yourusername/one-person-sop-generator.git

cd one-person-sop-generator
open index.html
```

## Usage / 使用方法

### 基础用法

1. 打开 `index.html`
2. 在「配置」Tab 选择业务类型、团队规模和阶段
3. 点击「生成SOP」
4. 在「SOP输出」Tab 查看生成的完整SOP
5. 点击「保存SOP」留存或「导出Markdown」下载

### 业务类型对应 SOP 模块

| 业务类型 | 客服 SOP | 财务 SOP | 营销 SOP | 交付 SOP |
|----------|:--------:|:--------:|:--------:|:--------:|
| 电商/实物产品 | 必需 | 必需 | 必需 | 必需 |
| 服务/咨询 | 必需 | 必需 | 必需 | 必需 |
| 内容/自媒体 | 非必需 | 必需 | 必需 | 必需 |
| 工具/SaaS | 必需 | 必需 | 必需 | 必需 |

### 导出的 Markdown 示例

```markdown
# 客服与服务 SOP

## 响应时效
- 工作时间（9:00-18:00）：30分钟内回复
- 非工作时间：次日上午10点前回复
- 紧急事项：15分钟内响应

## 标准处理流程
1. 确认客户身份（订单号/账号）
2. 记录问题描述
3. 判断问题类型
4. 提供解决方案
5. 确认客户满意度
6. 记录处理结果

## 常见问题模板
- Q: 如何退款？
  A: 请提供订单号，我们将在3个工作日内处理...
```
